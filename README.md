# MyScent

> 让调香像游戏一样可玩，让游戏中的每一步又真实影响香水结果。

MyScent 是一个连接制作场景、调配仪式、香味计算与现实调香逻辑的数字调香产品。

用户在场景中执行的取料、滴加、混合、静置、试闻和修正，会真实写入统一配方状态并影响数字香气预测；系统计算出的前中后调、属性、遮盖、冲突和调整建议，又会返回场景，成为可感知、可继续操作的反馈。

故事、香语、海报、视频和社区表达属于制作完成后的衍生层，而不是核心制作的前置条件。

## 产品核心

- **制作场景与调配仪式**：通过魔法师、精密实验室、东方香房、自然工坊等交互语言承载真实调配动作。
- **统一配方与香味计算**：所有场景共用同一材料、比例、前中后调、规则和版本状态。
- **玩家成长**：普通、进阶和高级玩家逐步看到更真实的材料与参数，但使用同一底层系统。
- **材料分层透明**：公开现实材料方向，按权限开放精确创作配方，保护生产批次与复现精度。
- **现实兑现**：后续连接外购材料录入、官方定量材料包、试香、合作生产与反馈修正。

## 材料透明原则

MyScent 不依赖隐藏材料名称形成壁垒。

采用：

> 公开材料真实性，保护复现精度。

用户可以学习真实材料，也可以自行外购。平台通过香味计算、配方换算、版本管理、授权、批次追踪、官方定量与预稀释、制作指导和试香反馈形成不可替代价值。

## 当前阶段

项目当前处于产品核心重构与 MVP 垂直切片定义阶段。首轮目标是验证：

1. 用户是否愿意完成一次真正可操作的数字调香；
2. 玩家是否理解自己的动作如何改变香味结果；
3. 制作场景和仪式是否增强体验，而不是遮蔽调香因果；
4. 普通玩家是否会主动试错、修正并保存版本；
5. 有经验玩家是否认可结果不是随机生成；
6. 用户是否愿意查看现实材料并进一步连接真实制作。

## 协作方式

整个项目统一采用 `product-development-ai-collaboration-plus`：

`Issue → Branch → Design/Development → PR → CI → Audit → Acceptance → Merge → Remote Readback`

- AI 可以负责分析、方案、文档、实现、测试和审计材料；
- 影响正式项目资产、范围、版本或发布状态的动作必须经过项目负责人确认；
- 默认通过独立分支和 Draft PR 交付，不直接修改或合并正式版本。
