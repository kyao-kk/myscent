# MyScent 产品愿景与定位

- 文档版本：v0.1
- 状态：Draft
- 对应 Issue：#1
- 产品口号：**把故事做成香水。**

## 1. 产品愿景

MyScent 希望让不具备专业调香知识的人，也能把一段情绪、记忆、关系、角色或世界观，转化为一款可以被理解、被传播、被试闻并最终被真实制作的香水作品。

产品不是单纯的香水推荐器，也不是把心理测试结果包装成香调。它要提供一套从数字创作到现实兑现的完整路径：

`故事/情绪输入 → 调香创作 → 香气结果预测 → 内容生成 → 作品发布 → 社区互动 → 配方或试香购买 → 真实反馈 → 配方迭代`

## 2. 产品定义

MyScent 是一个连接以下四种能力的香水作品平台：

1. **数字调香**：将用户的感受、场景和香调选择转译为受控、可追溯的香水方案。
2. **作品表达**：为每款香水生成名称、香语、故事、视觉、视频、声音和制作仪式。
3. **社区传播**：让香水成为可观看、可评论、可收藏、可二创的内容作品。
4. **真实兑现**：在后续阶段通过配方授权、试香、材料包或合作生产方制作成品。

## 3. 核心价值主张

### 3.1 对普通玩家

用户不需要先认识复杂原料，可以从情绪、颜色、天气、人物、关系、记忆和场景开始创作。系统把抽象描述转化为香调结构，并控制明显不合理的组合。

### 3.2 对有经验玩家

用户可以控制前调、中调、后调，调整甜度、冷暖、轻重、扩散感、留香倾向和香调占比，并保存不同版本。

### 3.3 对高级玩家

后续提供真实原料、稀释浓度、百分比、成本、挥发特征、相容性、限制与版本追踪。高级自由度必须与安全、合规和生产可行性校验同时存在。

### 3.4 对内容创作者

用户可以围绕小说角色、原创角色、关系、城市、季节、宠物、游戏世界观或个人经历创作香水作品，并通过作品传播、付费配方、二创和实物销售获得收益。

## 4. 产品三层核心

### 4.1 调香创作引擎

负责：

- 情绪、故事、场景与香调意图解析；
- 普通、进阶、高级三种创作深度；
- 前中后调结构建议；
- 香气属性预测；
- 冲突、遮盖和生产可行性提示；
- 版本管理与试香反馈修正。

首期采用“香气积木 + 规则模型 + 受控组合”，避免对普通玩家开放不可控的完全自由原料组合。

### 4.2 内容生成引擎

围绕香水作品生成：

- 香水名称；
- 一句话香语；
- 作品故事；
- 前中后调卡；
- 情绪与人格标签；
- 海报；
- 短视频；
- BGM、环境音与制作音效建议；
- 制作过程的场景化演绎。

内容用于帮助线上用户理解和感受作品，但不得替代真实试香，也不得被描述为对实际味道的绝对保证。

### 4.3 社区与交易引擎

负责：

- 作品发布、浏览、搜索和榜单；
- 点赞、评论、收藏、分享；
- 原作与二创关系；
- 配方展示范围和授权方式；
- 数字配方、模板、试香和成品交易；
- 创作者收益与平台抽佣；
- 订单、生产版本和批次追踪。

## 5. 制作场景与创作人格

调香过程不只表现为液体混合，而可以被包装为不同的创作仪式。MVP 首批场景：

### 5.1 魔法师 / 炼金术士

关键词：烛火、古书、药剂瓶、月光、符号、烟雾、仪式感。

建议音效：玻璃轻碰、火焰、翻书、液体滴落、低频神秘环境音。

### 5.2 化学师 / 精密实验室

关键词：透明器皿、冷光、数据曲线、滴定、精密设备、克制与秩序。

建议音效：仪器提示音、液体滴答、金属轻响、稳定电子氛围。

### 5.3 科学狂人

关键词：快速实验、涂改笔记、蒸汽、异常反应、戏剧张力和夸张节奏。

该风格适合后续短视频传播，但首期应限制为视觉表现，不虚构真实危险实验。

### 5.4 东方香房

关键词：木案、纸笺、铜炉、药柜、花木、研磨、窗影和安静仪式。

建议音效：研磨、木器、纸张、微风、水声和焚香氛围。

### 5.5 自然森系

关键词：清晨、雾气、露水、草叶、木屋、野花和疗愈感。

建议音效：风声、树叶、水滴、鸟鸣和远处流水。

MVP 首发采用魔法师、实验室、东方香房、自然森系四类；科学狂人作为后续实验模板。

## 6. 核心产品原则

### 6.1 香水优先，内容放大

故事、视频和音效用于帮助作品被理解与传播，但不能掩盖配方和真实试闻质量。最终商业价值必须回到香水本身是否具有可接受的气味表现。

### 6.2 受控自由

普通玩家获得易理解且不容易失败的创作空间；有经验玩家获得局部控制；高级玩家获得更多真实参数。自由度与风险提示、可生产性和安全校验同步提升。

### 6.3 预测而非绝对计算

系统输出的是基于材料特征、结构、比例和历史反馈的香气预测。原料批次、浓度、熟化、环境和人体差异都会影响实际结果。

### 6.4 先试香，再大规格购买

实物阶段优先提供 2ml/5ml 样品和多版本对比，不鼓励用户在未试闻的情况下直接购买大规格定制成品。

### 6.5 配方属于作品资产

作品必须记录作者、版本、公开范围、授权方式、二创关系和购买权益。购买配方不自动等于取得著作权、品牌权或无限制商业生产权。

### 6.6 合规生产

平台早期不自建工厂。真实试香和成品优先通过具备相应资质、质量体系和柔性生产能力的合作方完成。

## 7. 首期目标用户

MVP 优先服务三类人：

1. 喜欢氛围、文案、个性表达和 DIY 的年轻用户；
2. 对香水有基础认识、愿意反复调整香调的爱好者；
3. 擅长角色、故事、同人、原创世界观和短视频表达的内容创作者。

专业调香师和原料级高级玩家属于后续扩展用户，不作为 MVP 的核心成功前提。

## 8. 长期愿景

MyScent 长期可能成长为：

- 面向消费者的个人香水创作与购买平台；
- 面向创作者的气味内容社区和作品交易市场；
- 面向香水工作室、品牌与门店的数字调香 SaaS；
- 连接用户感知、配方、内容和柔性生产的数据基础设施。

长期护城河不是单次生成文案的模型能力，而是“配方结构—系统预测—真实试香—用户感知—修改行为—复购结果”之间持续积累的数据关系。
