## 0. 重要状态说明

本 PRD 的原始版本以“故事输入、内容生成、发布与社区互动”为主流程。项目负责人已确认该重心不准确。

当前正式方向已经调整为：

1. 制作场景与调配仪式是第一重心；
2. 玩家动作必须进入统一配方状态；
3. 香味计算、冲突、遮盖和调整建议必须由配方状态产生；
4. 计算结果必须回到场景成为可感知、可继续操作的反馈；
5. 真实材料按层级逐步公开，不以永久隐藏材料名称作为商业壁垒；
6. 故事、香语、自我表达、海报、视频和社区属于制作后的衍生层。

因此，本文件原有功能清单、页面结构、MVP指标和验收场景均需要重写。

在新的 MVP PRD 完成并经项目负责人确认前：

- 不得根据本文件直接进入全面开发；
- 不得把故事输入设为制作必填项；
- 不得优先建设完整作品社区；
- 不得将视频生成作为核心闭环依赖；
- 不得将普通模式退化为心理测试和一键生成；
- 不得因担忧用户外购而永久隐藏现实材料。

新的产品基线以以下文档为准：

## 1. 新版 MVP PRD 必须覆盖的范围

下一版 PRD 应至少包含：

1. 主制作场景和映射场景；
2. 制作空间、器具和身份；
3. 8至12个标准调配动作；
4. 操作与统一配方状态的映射；
5. 24个香气积木的使用规则；
6. 香味计算输入、输出和解释；
7. 场景内视觉、声音、仪器和文字反馈；
8. 冲突、遮盖、失衡、撤销和修正；
9. 普通、进阶和高级玩家的同底层分层；
10. 现实材料方向查看；
11. 配方可见性与授权预留；
12. 版本保存、对比和完成仪式；
13. 可选名称、香语和分享卡；
14. 移动优先页面流程；
15. MVP埋点与验收标准；
16. 最小运营后台和安全边界。

---

## 2. 新版 MVP 核心流程

`进入制作场景 → 选择目标或自由实验 → 查看和取用材料 → 执行调配动作 → 配方状态更新 → 香味计算 → 场景反馈 → 玩家修正 → 保存版本 → 完成香水 → 查看数字预测和现实材料方向 → 可选命名、分享或继续现实制作`

---

## 3. 新版 MVP 主要成功指标

首轮不再以发布率和社区互动率作为第一成功指标。

优先指标：

- 制作完成率；
- 主动调整率；
- 撤销、重做和替换使用率；
- 第二版本保存率；
- 用户对操作—结果因果的理解度；
- 普通玩家易用性；
- 有经验玩家对结果可信度的评价；
- 场景反馈与计算一致性；
- 现实材料方向查看率；
- 继续制作、试香或现实兑现意愿。
