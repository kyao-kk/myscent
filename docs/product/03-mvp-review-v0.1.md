## 1. 审查结论

产品方向成立，愿景、路线和核心闭环可以继续进入信息架构与原型阶段；但当前 PRD 仍不应直接冻结为开发范围。

本轮结论为：

> **有条件通过产品方向，要求先按本审查基线收缩 MVP、固定香气积木底层、限制音视频成本，并补齐最小运营后台。**

当前最大风险不是产品概念不成立，而是首版同时承担数字调香、生成式内容、视频、社区、版本、审核和社交互动，容易把需求验证做成一个开发量较大的完整社区产品。

## 2. 已确认的产品决策

### D-001 首发平台

首轮封闭测试采用：

- **移动端优先的响应式 Web；**
- 支持手机浏览器完成创作、发布、浏览和分享；
- 桌面浏览器保留较舒适的进阶编辑能力；
- 页面结构、接口和数据模型预留未来 App 与小程序外壳。

MVP 暂不优先建设：

- 原生 iOS/Android App；
- 微信小程序完整版本；
- 多端同时首发。

理由：

1. 分享链接可以直接打开作品，最适合验证内容传播；
2. 无需等待应用商店审核，便于快速改版；
3. 生成任务、视频预览、复杂表单和版本编辑在 Web 中更容易快速实现；
4. 首轮尚未证明用户愿意持续使用，不应过早承担多端维护成本。

未来进入条件：

- 若微信分享和社交流量占比明显较高，可增加小程序分发壳；
- 若用户产生稳定复访、推送、相册上传和重度创作需求，再评估原生 App。

### D-002 登录与游客体验

- 游客可以浏览公开作品；
- 游客可以完成一次普通模式创作，并看到完整数字香气草案和基础作品预览；
- 保存草稿、生成可导出视频、发布、评论、点赞和收藏前必须登录；
- 首轮国内测试优先采用手机号验证码；
- 游客登录后必须恢复登录前草稿，不要求重新生成。

该决策用于降低首次体验门槛，同时避免匿名生成滥用和资产归属不清。

### D-003 普通模式香气积木规模

MVP 采用 **24 个首批标准香气积木**，分为 8 个气味家族，每个家族 3 个积木。

原则：

- 普通用户看到的是易理解的气味意象，不看到原料级配方；
- 进阶用户可以看到家族、前中后调倾向和属性变化；
- 每个积木必须具有稳定 ID、版本和规则参数；
- 首批积木是数字创作结构，不宣称已等同于真实生产基底；
- 后续进入实物阶段时，为每个积木增加生产映射状态和合作方验证记录。

详细定义见 `04-scent-blocks-v0.1.md`。

### D-004 视频生成方式

MVP 不使用高成本、不可控的自由文生视频作为默认能力。

默认方案：

- 使用场景模板、静态生成背景或平台素材、轻动效、文字排版和授权音频进行合成；
- 输出竖屏 9:16；
- 建议输出 720 × 1280、约 15 秒；
- 四个场景各准备 3 套镜头结构，共 12 套基础模板；
- 视频内容由作品结构驱动，不由模型自由生成危险实验细节；
- 使用同一作品内容重复导出时复用已生成资产；
- 视频失败不得阻塞作品发布。

允许在后续小流量实验中测试生成式视频，但不得进入 MVP 核心依赖。

### D-005 媒体成本边界

以下数值是首轮内部预算假设，需要在技术方案和供应商测试后复核：

- 单个完成作品的文字、海报和视频平均可变成本目标：**不高于 1.50 元人民币；**
- 单作品预算预警线：**2.50 元人民币；**
- 超过预算时优先降级为模板海报或静态视频，不允许无上限重试；
- 每个作品默认提供 1 次正式视频生成和 1 次因内容实质修改产生的重新生成；
- 仅调整封面裁剪、字幕位置或导出尺寸时不得重新调用高成本生成服务；
- 必须按用户、作品、资产类型、服务商和重试原因记录成本。

上述数字不是对外承诺，也不是最终供应商报价。

### D-006 场景模板收费

MVP 四个首发场景全部免费：

1. 魔法师 / 炼金术士；
2. 精密实验室；
3. 东方香房；
4. 自然森系。

MVP 需要验证场景偏好，不能过早用付费墙破坏实验数据。高级场景、镜头、字体和音效包可在 V1 验证付费。

### D-007 基于作品开始创作

MVP 开放“基于这个主题创作”，但只允许带入：

- 公开主题；
- 场景模板；
- 标签；
- 可公开的情绪方向。

不得自动复制：

- 原作者故事全文；
- 香语；
- 完整香气结构；
- 私有输入；
- 未授权的视觉和声音资产。

该功能在 MVP 是低风险灵感入口，不等同于 V1 的正式二创或配方授权。

### D-008 社交范围

MVP 不建设关注关系和私信。

保留：

- 作者主页；
- 作品发布；
- 点赞；
- 收藏；
- 一级评论；
- 分享；
- 基于主题创作。

评论回复、独立通知中心、关注动态流和私信均进入后续优先级评估。

### D-009 内容审核策略

采用混合策略：

- 发布前对作品名称、故事、香语、标签和生成提示进行自动检查；
- 生成海报和视频完成后进行基础自动检查；
- 发布后提供举报、下架、限流和复核；
- 用户名、头像和评论也进入审核范围；
- 魔法师、实验室和科学狂人主题必须区分虚构表现与真实危险操作。

MVP 必须包含最小运营后台，至少支持：

- 作品列表与状态；
- 用户与评论查询；
- 举报列表；
- 下架、恢复和封禁；
- 审核原因与操作记录。

只设计前台举报入口但没有后台处理能力，不满足上线条件。

### D-010 首轮内测规模

建议第一轮封闭测试招募 100 至 150 人，保持三类用户都有足够样本：

- 普通氛围与 DIY 用户：约 50%；
- 香水爱好者：约 25%；
- 故事、OC、视觉或短视频创作者：约 25%。

招募不只依赖熟人，应至少包含一部分与项目团队无直接关系的目标用户，避免礼貌性反馈。

## 3. MVP 范围审查

### 3.1 当前问题

原 PRD 列出 18 个前台页面，同时包含搜索、消息通知、评论回复、完整版本对比和社区治理。以需求验证为目标，这一范围偏大。

首轮真正需要验证的是：

1. 用户是否愿意完成作品；
2. 内容表达是否增加发布和分享；
3. 别人是否愿意消费和互动；
4. 哪类故事、香气和制作场景产生持续偏好。

搜索、关注、复杂通知等能力不会直接决定上述假设是否成立。

### 3.2 P0：首轮封闭测试必须具备

建议 P0 合并为以下核心页面或页面组：

1. 登录与游客入口；
2. 发现首页；
3. 创作模式与故事意图输入；
4. 香气偏好与香气草案；
5. 轻量进阶编辑；
6. 制作场景选择；
7. 生成状态；
8. 作品预览与编辑；
9. 发布设置；
10. 作品详情与内嵌评论；
11. 我的作品、草稿和收藏；
12. 最小运营审核后台。

### 3.3 P1：MVP 验证期内按数据追加

- 独立搜索页；
- 独立评论页和多级回复；
- 独立消息通知中心；
- 复杂个人主页装饰；
- 高级版本对比图；
- 更多场景和视频模板；
- 个性化推荐算法。

### 3.4 明确不进入首轮

- 关注关系；
- 私信；
- 数字配方付费；
- 创作者分账；
- 实物试香和履约；
- 高级玩家原料级工作台；
- 自由文生视频；
- 复杂推荐系统。

## 4. 调香引擎审查

### 4.1 调香结果必须先于内容结果

正确依赖方向：

`用户输入 → 意图解析 → 香气积木与规则生成结构 → 冲突与置信度 → 名称/香语/故事 → 海报/视频/声音`

禁止的依赖方向：

`用户故事 → 模型自由写香调 → 再用漂亮文案合理化结果`

所有内容生成服务都必须读取同一个已确认的 `WorkVersion` 和 `ScentStructure`，避免海报、故事和视频分别产生互相矛盾的香气表达。

### 4.2 首版规则最少应覆盖

- 前调、中调、后调角色倾向；
- 家族占比；
- 甜度、清新、冷暖、轻重、柔锐、扩散和留香倾向；
- 喜欢与排斥；
- 主体不清；
- 甜厚过载；
- 明显冲突或遮盖；
- 单一积木过度主导；
- 组合可信度；
- 当前结构是否只适合数字实验。

### 4.3 置信度不能由语言模型自行编造

置信度至少应由以下可计算因素组成：

- 是否全部使用标准积木；
- 是否落在已定义的占比范围；
- 是否命中冲突规则；
- 是否存在未验证组合；
- 用户是否进行了超出建议范围的修改；
- 规则和积木版本是否完整。

MVP 可输出高、中、实验性三级，不必伪造精确百分比。

## 5. 内容与视频审查

### 5.1 场景不能改写香气

四种制作场景是作品表达层。用户切换场景时默认只改变：

- 视觉；
- 镜头；
- 字体与排版；
- BGM；
- 环境音；
- 制作音效；
- 文案语气的有限风格化。

只有用户明确选择“根据场景微调香气”并确认差异，才能产生新的 `WorkVersion`。

### 5.2 视频最小可行结构

每个 15 秒视频建议采用四段结构：

1. 0–3 秒：主题与氛围建立；
2. 3–8 秒：场景化调配动作；
3. 8–12 秒：前中后调或气味关键词；
4. 12–15 秒：作品名称、香语与作者落版。

所有字幕、镜头和音效必须从作品结构中读取。视频不能出现与香调无关的随机奇观。

### 5.3 音频

- BGM、环境音和制作音效分轨配置；
- 默认允许用户单独关闭任一轨；
- 发现页默认静音自动播放；
- 作品详情由用户主动开启声音；
- 保存音频来源、授权范围、版本和使用期限；
- 授权不明确的素材不得进入正式模板库。

## 6. 首轮成功门槛

以下阈值作为首轮验证假设，不代表长期 KPI：

- 进入创作后的作品草案完成率：不低于 35%；
- 完成作品后的公开或私密保存率：不低于 60%；
- 完成作品后的公开发布率：不低于 30%；
- 7 日内再次创建作品的用户比例：不低于 20%；
- 公开作品中获得至少一次非作者互动的比例：不低于 25%；
- 海报或视频分享/导出率：不低于 15%；
- 视频生成失败不得使整体创作完成率下降超过 5 个百分点；
- 至少一个场景在去除默认排序影响后仍表现出稳定偏好。

进入 V1 前，还应出现用户主动询问配方、复刻、试香或购买方式的行为信号。
