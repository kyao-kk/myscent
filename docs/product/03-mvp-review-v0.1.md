## 1. 审查结论

产品方向成立，愿景、路线和核心闭环可以继续进入信息架构与原型阶段；但当前 PRD 仍不应直接冻结为开发范围。

本轮结论为：

> **有条件通过产品方向，要求先按本审查基线收缩 MVP、固定香气积木底层、限制音视频成本，并补齐最小运营后台。**

当前最大风险不是产品概念不成立，而是首版同时承担数字调香、生成式内容、视频、社区、版本、审核和社交互动，容易把需求验证做成一个开发量较大的完整社区产品。

后续经过项目负责人进一步修正，产品主轴明确为：

> **制作场景与调配仪式承载游戏体验，统一配方状态与香味计算保证实际因果，故事与自我表达属于衍生层。**

真实材料采用分层透明策略，不因担忧用户外购而永久隐藏材料名称。

## 2. 已确认的产品决策

### D-001 首发平台

首轮封闭测试采用：

- **移动端优先的响应式 Web；**
- 支持手机浏览器完成创作、发布、浏览和分享；
- 桌面浏览器保留较舒适的进阶编辑能力；
- 页面结构、接口和数据模型预留未来 App 与小程序外壳。

MVP 暂不优先建设：

- 原生 iOS/Android App；
- 微信小程序完整版本；
- 多端同时首发。

理由：

1. 分享链接可以直接打开作品，最适合验证内容传播；
2. 无需等待应用商店审核，便于快速改版；
3. 生成任务、视频预览、复杂表单和版本编辑在 Web 中更容易快速实现；
4. 首轮尚未证明用户愿意持续使用，不应过早承担多端维护成本。

未来进入条件：

- 若微信分享和社交流量占比明显较高，可增加小程序分发壳；
- 若用户产生稳定复访、推送、相册上传和重度创作需求，再评估原生 App。

### D-002 登录与游客体验

- 游客可以浏览公开作品；
- 游客可以完成一次普通模式创作，并看到完整数字香气草案和基础作品预览；
- 保存草稿、生成可导出视频、发布、评论、点赞和收藏前必须登录；
- 首轮国内测试优先采用手机号验证码；
- 游客登录后必须恢复登录前草稿，不要求重新生成。

该决策用于降低首次体验门槛，同时避免匿名生成滥用和资产归属不清。

### D-003 普通模式香气积木规模

MVP 采用 **24 个首批标准香气积木**，分为 8 个气味家族，每个家族 3 个积木。

原则：

- 普通用户看到的是易理解的气味意象，不看到原料级配方；
- 进阶用户可以看到家族、前中后调倾向和属性变化；
- 每个积木必须具有稳定 ID、版本和规则参数；
- 首批积木是数字创作结构，不宣称已等同于真实生产基底；
- 后续进入实物阶段时，为每个积木增加生产映射状态和合作方验证记录。

详细定义见 `04-scent-blocks-v0.1.md`。

### D-004 视频生成方式

MVP 不使用高成本、不可控的自由文生视频作为默认能力。

默认方案：

- 使用场景模板、静态生成背景或平台素材、轻动效、文字排版和授权音频进行合成；
- 输出竖屏 9:16；
- 建议输出 720 × 1280、约 15 秒；
- 四个场景各准备 3 套镜头结构，共 12 套基础模板；
- 视频内容由作品结构驱动，不由模型自由生成危险实验细节；
- 使用同一作品内容重复导出时复用已生成资产；
- 视频失败不得阻塞作品发布。

允许在后续小流量实验中测试生成式视频，但不得进入 MVP 核心依赖。

### D-005 媒体成本边界

以下数值是首轮内部预算假设，需要在技术方案和供应商测试后复核：

- 单个完成作品的文字、海报和视频平均可变成本目标：**不高于 1.50 元人民币；**
- 单作品预算预警线：**2.50 元人民币；**
- 超过预算时优先降级为模板海报或静态视频，不允许无上限重试；
- 每个作品默认提供 1 次正式视频生成和 1 次因内容实质修改产生的重新生成；
- 仅调整封面裁剪、字幕位置或导出尺寸时不得重新调用高成本生成服务；
- 必须按用户、作品、资产类型、服务商和重试原因记录成本。

上述数字不是对外承诺，也不是最终供应商报价。

### D-006 场景模板收费

MVP 四个首发场景全部免费：

1. 魔法师 / 炼金术士；
2. 精密实验室；
3. 东方香房；
4. 自然森系。

MVP 需要验证场景偏好，不能过早用付费墙破坏实验数据。高级场景、镜头、字体和音效包可在 V1 验证付费。

### D-007 基于作品开始创作

MVP 开放“基于这个主题创作”，但只允许带入：

- 公开主题；
- 场景；
- 公开标签；
- 用户自行选择是否参考的香调方向。

不得直接复制：

- 原作者未公开的配方结构；
- 用户私密输入；
- 未授权故事正文；
- 生产配方。

### D-008 关注关系

MVP 不建设关注关系和个性化推荐网络。

保留：

- 作者主页；
- 作品列表；
- 点赞、收藏、评论；
- 从作者主页继续浏览。

原因是首轮需要先验证作品消费，而不是提前建立社交图谱。

### D-009 内容审核策略

采用混合策略：

- 输入和生成阶段进行基础自动检查；
- 公开发布前检查高风险内容；
- 普通内容发布后允许举报与人工处理；
- 涉及危险化学步骤、违法制毒、自伤指导、严重侵权或其他高风险内容时阻止公开发布。

### D-010 首轮内测规模

建议首轮封闭测试招募 **100 至 150 人**，分为：

- 普通年轻用户约 60%；
- 香水爱好者约 25%；
- 故事、角色、视觉或视频创作者约 15%。

测试不以人口代表性为首要目标，重点是发现创作流程断点、内容吸引力和调香可信度问题。

### D-011 制作与计算优先

MVP 核心不再以故事创作和社区发布为先，而以一个可玩的调香垂直切片为先。

必须先验证：

- 玩家动作是否真实修改统一配方状态；
- 香味计算是否能解释变化；
- 场景反馈是否帮助理解；
- 普通玩家是否会主动试错和修正；
- 同一配方在不同场景中的底层结果是否一致。

故事、香语、海报、视频和社区属于完成后的可选衍生能力。

### D-012 真实材料分层透明

项目负责人已确认采纳以下设计：

> **公开材料真实性，保护复现精度；允许用户学习和外购，但让平台在计算、便利、稳定、安全、版本管理和现实兑现上不可替代。**

信息分为四层：

1. 意象与游戏交互层；
2. 真实材料方向层；
3. 精确创作配方层；
4. 生产与批次配方层。

普通玩家可按需了解真实材料方向；进阶玩家可看到代表性材料与相对作用；高级玩家按授权查看精确创作配方；供应商、批次、生产比例和打样修正默认不公开。

允许用户自行外购并录入材料。官方材料包必须通过定量、预稀释、扫码映射、软件指导、批次记录与调整服务形成价值。

详细策略见 `06-material-transparency-and-fulfillment-v0.1.md`。

## 3. MVP 范围审查

原 PRD 前台页面和社区功能过重。重构后应分为：

### P0：必须进入首个垂直切片

- 制作场景入口；
- 材料/香气积木选择；
- 取料、滴加、增减、替换、混合、静置表现；
- 统一配方状态；
- 香味属性与前中后调计算；
- 场景反馈；
- 撤销、重做和版本保存；
- 冲突、遮盖和失衡修正；
- 完成仪式与结果页；
- 真实材料方向查看；
- 基础登录与配方收藏。

### P1：核心验证通过后增加

- 第二个完整场景；
- 海报和分享卡；
- 可选名称、香语与故事；
- 公开作品页；
- 点赞、收藏与基础评论；
- 模板化视频；
- 基于主题开始创作。

### 暂缓

- 关注关系；
- 私信；
- 复杂推荐；
- 数字配方交易；
- 实物履约；
- 创作者分账；
- 完整原料级高级工作台；
- 完整材料商城。

## 4. 第一轮通过条件

在进入开发冻结前，至少需要完成：

1. 重写 MVP PRD，使制作动作和计算成为主流程；
2. 明确主场景和映射场景；
3. 定义统一配方状态；
4. 固定首批香气积木字段；
5. 定义首批标准操作；
6. 定义计算输入、输出和解释规则；
7. 明确材料透明度、权限和授权字段；
8. 补充最小运营与内容安全后台；
9. 输出垂直切片页面流程和验收标准。

当前仍为 Draft，不允许据现有旧版 PRD 直接全面开发。
