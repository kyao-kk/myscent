# MyScent 精密实验室工作台低保真设计

- 文档版本：v0.1
- 状态：Draft for Interaction Review
- 对应 Issue：#1
- 对应 PR：#2
- 适用阶段：P0-A 因果模型原型
- 目标设备：移动端优先响应式 Web

## 1. 设计目标

P0-A 的工作台不是展示成品海报的页面，而是玩家真正完成调香操作的核心空间。

它必须同时做到：

1. 玩家能够直观看见并操作材料；
2. 每个动作有即时、明确但不过度夸张的反馈；
3. 完整香味分析需要主动触发，形成一次“数字闻香”仪式；
4. 专业信息可以展开，但不会压垮普通玩家；
5. 配方、分析、版本和同步状态始终可辨认；
6. 页面刷新、分析失败和网络中断不会让用户失去实验成果。

## 2. 移动端页面骨架

```text
┌──────────────────────────────┐
│ 返回  实验 #A014      同步✓  │
│ 精密实验室     [切换场景]    │
├──────────────────────────────┤
│                              │
│       当前调配容器            │
│   液体 / 光效 / 层次反馈       │
│                              │
│  主体：透明白花               │
│  简报：清新↑ 透明↑ 尾段偏弱   │
│                              │
├──────────────────────────────┤
│ [撤销] [混合] [静置] [数字闻香]│
├──────────────────────────────┤
│ 当前配方                      │
│ 佛手柑亮光  4份  [-] [+] [...]│
│ 透明白花    6份  [-] [+] [...]│
├──────────────────────────────┤
│ 材料架  柑橘｜花香｜木质｜更多 │
│ [材料卡] [材料卡] [材料卡]     │
└──────────────────────────────┘
```

移动端默认只显示当前最重要的信息：

- 当前主体；
- 最近一次动作导致的主要变化；
- 是否存在严重遮盖、冲突或阶段缺失；
- 当前配方材料和相对份数；
- 四个高频动作：撤销、混合、静置、数字闻香。

8 项属性、完整证据和版本对比放入可展开面板。

## 4. 核心工作台区域

### 4.1 顶部状态栏

展示：

- 配方临时名或实验编号；
- 当前场景；
- 本地/同步中/已同步/冲突状态；
- 当前 revision；
- 是否存在未重新分析的修改。

禁止仅使用颜色表达同步或错误状态。

### 4.2 当前调配容器

容器负责表现当前配方整体状态，但不作为数据源。

可以表现：

- 液体明暗；
- 透明度；
- 轻重与流动速度；
- 顶部、中部、底部的层次提示；
- 主体被遮盖时的浑浊或覆盖表现；
- 分析完成后的稳定纹理。

不能表现为：

- 未经规则支持的真实化学反应；
- 有毒、爆炸或危险步骤的可模仿演示；
- 与实际计算无关的随机颜色变化；
- “动画看起来成功”但计算结果存在严重问题。

### 4.3 即时反馈条

每次修改后最多显示三项：

1. 变化最大的属性；
2. 主体是否改变；
3. 新触发的严重规则。

示例：

> 加入 1 份焦糖糖衣：甜度明显上升，透明度下降；雨后空气开始被遮盖。

即时反馈不展示完整分析，避免每次操作都打断节奏。

### 4.4 当前配方列表

每个组件显示：

- 意象名称；
- 家族图标；
- 相对份数；
- 主体/辅助/修饰标识；
- 增加、减弱和更多操作；
- 若数据异常，显示置信度提示。

更多操作包含：

- 设定份数；
- 替换；
- 移除；
- 查看详情；
- 查看现实材料方向。

### 4.5 材料架

默认按 8 个家族浏览。

材料卡首层只显示：

- 名称；
- 一句话气味描述；
- 常见阶段倾向；
- 当前配方中是否已存在。

展开后显示：

- 8 项属性简图；
- 强度提示；
- 常见用途；
- 兼容、遮盖和冲突提示；
- 现实材料方向；
- “不等于完整生产配方”声明。

### 4.6 数字闻香面板

玩家主动点击“数字闻香”后进入完整分析状态。

面板顺序：

1. 一句话结论；
2. 前、中、后调；
3. 当前主体和辅助；
4. 8 项属性；
5. 清晰度、复杂度、连续性、平衡度；
6. 当前问题；
7. 为什么会这样；
8. 最多 3 个调整方向；
9. 置信度与预测边界。

每个建议必须有明确动作按钮，但按钮只把目标带回工作台，不自动修改。

示例：

- “去减弱焦糖糖衣”；
- “去加入清苦香草”；
- “从当前状态建立分支再实验”。

## 5. 关键界面状态

### S-01 空实验

- 容器为空；
- 材料架展开；
- 数字闻香不可用；
- 引导用户选择第一种材料；
- 不弹出故事、性格或问卷。

### S-02 已选材料但未加入

- 材料详情浮层显示；
- 用户选择加入份数；
- 可查看现实材料方向；
- 取消后配方不变化。

### S-03 编辑中且分析过期

- 当前容器和即时反馈更新；
- 上一次完整分析保留但标记“基于 revision N”；
- 显示“配方已修改，请重新数字闻香”；
- 不把旧数值显示成当前数值。

### S-04 即时分析中

- 工作台仍可操作；
- 只显示局部加载状态；
- 较晚返回的旧 revision 结果不得覆盖新状态。

### S-05 完整数字闻香中

- 当前 revision 建立不可变分析快照；
- 播放简短分析仪式；
- 用户仍可退出面板；
- 若用户继续修改，当前任务返回后标记为旧 revision 分析。

### S-06 分析完成

- 显示完整结果；
- 可保存版本或继续调整；
- 完成按钮可用；
- 任何新修改立即使分析转为过期。

### S-07 严重问题

问题可以包括：

- 甜厚过载；
- 主体被遮盖；
- 中段缺失；
- 尾段不足；
- 材料冲突；
- 氛围无主体。

工作台不显示“失败”大红叉，而显示：

- 当前问题；
- 证据；
- 调整方向；
- 保留实验性配方的选项。

### S-08 撤销成功

- 配方恢复到上一个可撤销状态；
- 显示被撤销动作；
- 分析状态按恢复后的 revision 判断；
- 若公式哈希与历史分析一致，可以复用历史分析快照。

### S-09 版本保存

- 当前分析必须为最新；
- 用户可填写版本标签；
- 保存后显示版本节点；
- 继续修改不会覆盖该节点。

### S-10 封存完成

- 保存不可变配方版本；
- 显示最终预测和材料方向；
- 可选命名；
- 故事、香语和海报入口放在封存之后；
- 再次修改必须“从此版本建立新分支”。

### S-11 同步失败

- 本地命令日志继续保存；
- 明确显示尚未同步；
- 不阻止离线继续实验；
- 恢复网络后按命令顺序重试。

### S-12 revision 冲突

- 阻止继续提交远端修改；
- 显示远端与本地差异；
- 提供“载入远端”和“保留本地为新分支”；
- 禁止静默合并材料份数。

## 6. 动作映射

| 玩家动作 | 标准命令 | 数据结果 | 实验室反馈 |
|---|---|---|---|
| 拖入材料 | `component.add` | 新增组件与 revision | 移液器加入容器 |
| 点击加一格 | `component.increase` | 相对份数增加 | 刻度和液滴变化 |
| 点击减一格 | `component.decrease` | 相对份数减少 | 抽回少量组分 |
| 替换材料 | `component.replace` | 原子性移除并新增 | 取出旧试管、换入新试管 |
| 移除材料 | `component.remove` | 组件失效 | 抽离该组分 |
| 撤销 | `operation.undo` | 追加补偿事件 | 仪表回退与简短回放 |
| 混合 | 流程动作 | 操作日志与反馈节点 | 搅拌或摇匀 |
| 静置 | 流程动作 | 阶段观察节点 | 稳定计时表现 |
| 数字闻香 | `analysis.request full` | 固定 revision 完整分析 | 分析仪扫描 |
| 保存版本 | `version.snapshot` | 不可变快照 | 试管归档 |
| 封存 | `formula.seal` | 不可变完成版本 | 封签与编号 |

## 7. 普通与进阶模式

两种模式使用同一个工作台和配方数据。

### 普通模式隐藏

- 精确有效贡献；
- 规则强度；
- 内部置信度构成；
- 完整参数表。

普通模式显示：

- 份数；
- 强弱；
- 前中后调倾向；
- 易懂的问题与建议；
- 可主动展开的现实材料方向。

### 进阶模式增加

- 归一化相对比例；
- 家族贡献；
- 阶段贡献；
- 遮盖方向；
- 规则证据 ID；
- 版本数值差异。

模式切换不能改变配方和结果。

## 8. 低保真验收场景

### A. 首次完成

用户不看教程，也能：

1. 加入 3 种材料；
2. 调整份数；
3. 执行数字闻香；
4. 看懂一个问题；
5. 亲自修正；
6. 保存版本。

### B. 遮盖修正

用户加入焦糖后，系统说明雨后空气被遮盖。用户可以定位焦糖、减弱一格，再看到透明度回升。

### C. 撤销可信

用户撤销后：

- 容器表现恢复；
- 配方份数恢复；
- 公式哈希恢复；
- 数值恢复或复用历史分析；
- 操作记录保留撤销事件。

### D. 场景独立

切换到魔法师测试壳后：

- 配方不变化；
- 数值不变化；
- revision 不变化；
- 只有器具、措辞、动画和声音变化。

## 9. 可用性要求

- 主要操作触控目标不小于 44×44 CSS 像素；
- 所有声音可关闭；
- 关键反馈同时提供文字；
- 动画提供减少动态效果选项；
- 数字闻香面板支持键盘和屏幕阅读器顺序；
- 不用颜色作为唯一错误、阶段或同步标识；
- 高级数据面板不阻塞普通制作路径。

## 10. P0-A 结束时不追求的视觉内容

- 真实玻璃折射；
- 高精度液体模拟；
- 完整 3D 实验室；
- 多角色剧情；
- 大量收集和装修系统；
- 电影级完成动画。

P0-A 首先证明：

> 用户的每一个调配动作都能被看见、被计算、被解释、被撤销、被保存，并且值得继续尝试下一版。
