# MyScent 首发场景与固定资源清单 v0.1

- 状态：Draft for Art Production
- 依赖：`00-visual-theme-baseline-v0.1.md`
- 首发场景：魔法师的调香台

## 1. 场景构图

画面以横向工作台为主体，中央为调配区，背景通过圆窗和架子建立世界观。

### 1.1 三层空间

1. **远景层**
   - 圆形拱窗；
   - 远方城堡、森林或雾中建筑；
   - 冷色天空和柔和体积光。

2. **中景层**
   - 木架、少量瓶罐、悬挂植物；
   - 一盏炼金灯或暖光灯；
   - 不可交互，只承担氛围和纵深。

3. **前景工作台层**
   - 所有核心操作发生在这里；
   - 交互物边缘清楚；
   - 桌面不得被装饰性物体填满。

## 2. 固定工作台布局

### 中央调配区

- 主调配容器：1个；
- 称量设备或魔法平衡盘：1个；
- 当前液体状态展示：集成在主容器中；
- 滴加落点：固定在容器中央。

### 左侧准备区

- 材料架：最多5个当前可选材料瓶；
- 滴管：1支；
- 量取器具：1个；
- 当前选中材料的局部信息。

### 右侧修正区

- 研钵或混合工具：1个；
- 配方笔记本：1本；
- 简短反馈区：最多显示一个主要问题和一个建议动作。

### 背景氛围物

- 晶体或魔法媒介：1组；
- 暖光灯/炼金灯：1盏；
- 植物或干燥香材：1组；
- 背景瓶罐不得超过12个可见轮廓，且不具备交互高光。

## 3. 首批固定资源

### 3.1 场景资源

- `SCENE_ALCHEMY_BG_FAR`：窗外远景；
- `SCENE_ALCHEMY_BG_ROOM`：墙面、木架与室内结构；
- `SCENE_ALCHEMY_BG_ATMOSPHERE`：雾、尘埃和光束；
- `SCENE_ALCHEMY_TABLE`：桌面与固定阴影；
- `SCENE_ALCHEMY_FOREGROUND`：前景遮挡和边缘暗角。

### 3.2 核心交互道具

- `PROP_MAIN_VESSEL`：主调配容器；
- `PROP_SCALE_OR_BALANCE`：称量设备/平衡盘；
- `PROP_DROPPER`：滴管；
- `PROP_MEASURE_CUP`：量取器；
- `PROP_MORTAR`：研钵；
- `PROP_NOTEBOOK`：配方笔记本；
- `PROP_MATERIAL_RACK`：五格材料架；
- `PROP_ALCHEMY_LAMP`：炼金灯；
- `PROP_CRYSTAL_CLUSTER`：晶体媒介。

### 3.3 材料瓶模板

只制作3种基础瓶型，通过颜色、标签符号和瓶塞变化生成首批24个香气积木，避免24套完全不同造型。

- `BOTTLE_TYPE_A_LIGHT`：轻盈、清新、前调类；
- `BOTTLE_TYPE_B_HEART`：花香、绿意、中调类；
- `BOTTLE_TYPE_C_BASE`：木质、琥珀、麝香、后调类。

每个材料瓶必须包含：

- 默认状态；
- 悬停/选中状态；
- 被拿起状态；
- 锁定状态；
- 空瓶或不可用状态。

## 4. UI固定资源

首批UI只制作以下组件：

- 当前配方条；
- 材料选择卡；
- 数量控制；
- 当前反馈卡；
- 撤销按钮；
- 分析按钮；
- 保存版本按钮；
- 单一风险提示；
- 简化前中后调条；
- 8项属性中与当前动作最相关的2—3项变化提示。

首发不制作：

- 常驻完整雷达图；
- 常驻完整香调金字塔；
- 常驻100分评分大卡；
- 同时展开的材料库、配方库、社区和项目列表；
- 多层导航抽屉。

## 5. 分层导出要求

### 主场景

- 设计母版：1920×1080 或更高；
- 保留分层PSD/PSB；
- Web导出优先使用WebP；
- 远景、中景、工作台、前景至少4层；
- 可交互道具独立透明图层；
- 液体、光效和阴影不可烘焙到同一层。

### 道具

- 透明背景；
- 正常、选中、操作中三种基础状态；
- 统一光源方向；
- 保留接触阴影独立层；
- 移动端最小显示尺寸下仍可识别。

### UI

- 图标优先SVG；
- 绘画纹理与装饰框可使用WebP；
- 九宫格面板必须保留可拉伸区域；
- 不将文字烘焙进图片。

## 6. 构图验收

一张正式工作台画面必须同时满足：

- 第一眼看到主调配容器；
- 第二眼看到当前材料和滴管；
- 第三眼才注意到背景世界；
- 不需要寻找就能理解“在哪里加入材料”；
- 关闭全部UI后，画面仍是一张完整的厚涂幻想场景；
- 开启UI后，中央制作区仍保持至少60%的无遮挡面积；
- 不出现“素材陈列板”或“仪表盘墙”的观感。
