# MyScent 视觉主题基线 v0.1

- 状态：**Approved / Frozen for first scene production**
- 用户确认：2026-07-14
- 首发主题：**魔法师的调香台 / Alchemy Perfume Workbench**
- 适用范围：UI、美术、动态、场景、固定资源

## 1. 核心方向

MyScent 首发视觉不采用写实摄影、豪华商品展示、3D渲染仪表盘或高密度数据看板。

正式风格固定为：

> **厚涂板绘的魔法调香场景，保留笔触和绘画质感，同时让每个可操作元素拥有清晰轮廓、明确层级和可识别功能。**

场景首先是一张有氛围、可进入、可操作的游戏画面；UI只辅助玩家完成调配，不占据画面主导权。

## 2. 视觉关键词

- 厚涂板绘
- 半写实幻想
- 温暖、安静、神秘
- 手工制作感
- 魔法与实际调香共存
- 清晰的道具剪影
- 克制的金色点缀
- 有层次但不繁杂

## 3. 明确禁止

以下方向不得继续使用：

- 摄影级写实桌面；
- 过度豪华的香水广告质感；
- 大量玻璃瓶、器械和装饰同时堆满桌面；
- 多个大型数据面板常驻；
- 雷达图、评分卡、香调金字塔同时争夺视觉中心；
- 大量发光粒子、光圈和金色特效同时播放；
- 纯黑金金融看板风格；
- 过于干净的现代实验室；
- 卡通Q版、扁平插画或儿童游戏风；
- 为了“高级”而牺牲可操作物体的清晰度。

## 4. 画面主次

首发工作台画面采用以下视觉占比：

- **70%–80%：制作场景与工作台**；
- **15%–20%：当前操作与即时反馈**；
- **不超过10%：辅助说明、数值和导航**。

任一时刻：

- 常驻UI区域不超过3个；
- 浮层不超过1个；
- 桌面核心可交互道具不超过8个；
- 同时播放的显著特效不超过2种；
- 只允许一个明确视觉焦点。

## 5. 首发场景气质

### 魔法师的调香台

场景位于一间有人长期使用的炼金与调香工作室：

- 木质工作台；
- 巨大的圆形拱窗；
- 窗外可见朦胧森林、塔楼或远方城堡；
- 暖色室内光与偏冷自然光交叠；
- 墙面与架子上有少量背景瓶罐，但不得抢夺主体；
- 桌面存在真实调香器具，也存在少量魔法媒介；
- 场景应让玩家感到“这里真的可以制作一瓶香水”。

## 6. 色彩基线

主色：

- 炭黑 / 深褐：背景与UI底色；
- 旧金 / 黄铜：交互焦点与边框；
- 琥珀：液体与暖光；
- 苔绿：植物和自然材料；
- 羊皮纸米色：说明、笔记和标签；
- 冷灰蓝：窗外环境与空间层次。

原则：

- 大面积低饱和；
- 高饱和颜色只用于当前选中材料、液体变化或风险反馈；
- 金色是操作强调色，不是全屏装饰色；
- 单屏主要色相不超过4组。

## 7. 光影基线

- 主光：偏暖、柔和、方向明确；
- 辅光：来自圆窗的冷色自然光；
- 玻璃、液体和金属只保留必要高光；
- 体积光用于空间深度，不覆盖操作区域；
- 当前操作物通过边缘光、局部亮度和背景压暗被突出；
- 禁止所有道具同时发亮。

## 8. 板绘质量要求

厚涂不等于模糊。所有可交互道具必须满足：

- 缩小到移动端仍可识别轮廓；
- 主体与背景有明确明度差；
- 功能相近的器具拥有不同剪影；
- 瓶体、滴管、量杯、研钵、天平不能混成一团；
- 标签可以简化，但材料颜色、瓶型和符号必须可区分；
- 背景细节使用概括笔触，交互物使用更清晰的边缘与局部细节。

## 9. UI气质

UI采用“绘画场景上的克制操作层”，不是大型控制台。

- 深色半透明哑光面板；
- 细旧金描边；
- 少量羊皮纸纹理；
- 中文为主；
- 数值只在与当前动作有关时出现；
- 图标优先于长文字；
- 默认状态弱化，选中状态增强；
- 面板必须避开中央制作区域。

首发常驻UI只保留：

1. 当前配方简要状态；
2. 当前操作/材料选择；
3. 一条简洁反馈或下一步提示。

## 10. 产品主轴约束

视觉必须持续表达：

> 玩家不是在填写问卷，也不是在观看AI生成故事，而是在一个有游戏感的场景里亲自调配，并看到每一步对真实配方和香味预测造成的变化。

故事、香语、命名和分享画面只能出现在制作完成后的衍生阶段，不进入首发工作台的主要视觉中心。
